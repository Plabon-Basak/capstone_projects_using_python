# Day 91: Personal Finance Dashboard

A CLI-based personal finance dashboard for **Python Mastery: 100 Days, 100 Projects**.

## Features

- Manage checking, savings, and credit accounts
- Record income and expense transactions
- Calculate net worth and monthly cash flow
- Group spending by category
- Calculate the monthly savings rate
- Compare category spending with budgets
- Return realistic JSON-style responses

## Project Structure

- `app.py` — CLI request/response demonstration
- `accounts.py` — account model, balances, and net-worth calculation
- `transactions.py` — transaction model and recording rules
- `dashboard.py` — financial summary and budget reporting

## Requirements

- Python 3.10 or newer
- No third-party packages

## Run

```bash
python app.py
```

The demo records sample monthly activity and generates a dashboard showing account balances, cash flow, spending categories, savings rate, and budget status.

> This educational project demonstrates software design and does not provide financial advice.
