# Day 95: Stock Price Prediction Tool

An educational CLI tool that fits a simple linear trend, calculates a moving average, predicts the next sample price, and reports backtest error.

## Structure
- `app.py` — prediction demo
- `market_data.py` — historical price model
- `predictor.py` — trend and moving-average calculations
- `evaluation.py` — walk-forward error measurement

cd /Users/arjunvaid/Desktop/sucess_plan/python_mastery_100_days_100_projects/day_95_stock_price_prediction_tool
