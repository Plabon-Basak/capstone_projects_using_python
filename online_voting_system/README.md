# Day 96: Online Voting System

A CLI voting backend with eligibility tokens, one-vote enforcement, candidate validation, anonymized receipts, results, and an audit log.

## Structure
- `app.py` — voting demo
- `elections.py` — election model and catalog
- `voting.py` — vote validation and counting
- `audit.py` — hashed voter receipts and event history
