# Day 98: Fitness Tracker App

A CLI fitness backend that logs workouts, totals activity and calories, tracks weekly goals, and generates a dashboard report.

## Structure
- `app.py` — tracker demo
- `workouts.py` — workout model and logging
- `goals.py` — weekly targets and progress
- `reports.py` — dashboard aggregation
