# Day 97: Restaurant Ordering System

A CLI restaurant backend with a menu, table orders, line-item totals, availability checks, and kitchen status progression.

## Structure
- `app.py` — ordering demo
- `menu.py` — menu items and availability
- `orders.py` — order creation and totals
- `kitchen.py` — preparation workflow
