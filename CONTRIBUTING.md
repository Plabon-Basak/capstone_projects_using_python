# Contributing

Thanks for your interest in this capstone collection! Each project is a self-contained demonstration written only with the Python standard library.

## How to contribute

1. Pick a project folder and read its `README.md`.
2. Open an issue to discuss substantive changes before opening a PR.
3. Fork the repository and create a feature branch.
4. Keep changes small and scoped to a single project.
5. Verify your change runs with the project's README instructions (Python 3.10+, no third-party packages).

## What fits this repo

- Bug fixes and clarifications to existing projects
- Documentation improvements (READMEs, docstrings)
- Unit tests that run with `python -m unittest`

## What does not fit

- New standalone projects (open a discussion first)
- Third-party dependencies
- Changes that break the "no external packages" rule
