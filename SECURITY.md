# Security Policy

## Reporting a Vulnerability

This repository contains educational capstone projects that run only with the
Python standard library. They are demonstrations, not production services.

If you believe you have found a security issue in any of these projects,
please report it responsibly instead of opening a public issue.

**Please do not open a public issue for security vulnerabilities.**

Instead, report privately by email to **plabonbasak0@gmail.com**. Include:

- The project folder affected
- A short description of the issue
- Steps to reproduce, if possible

We will acknowledge receipt within 5 business days and work with you toward a
resolution. Public disclosure is appreciated after a fix is available.
